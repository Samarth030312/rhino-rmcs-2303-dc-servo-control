# Incident 2026-10-11 — motor ran away; software STOP did not stop it

**Rig:** genuine Arduino Uno R3 (SN 4423831393835191C0B1), RMCS-2303 drive (slave id 7), RMCS-5032
motor, 11.2 V battery, no power switch. Logs: `results/evidence/logs/hw_session_20261011-122159.log`
and the flash logs of 12:24–12:30.

## What happened

1. 12:23:55 First motion test: open loop, +20.16 rpm commanded. The drive's speed feedback read
   **−16 140 … −16 605 base rpm (−161 … −166 output rpm)**: full speed, the wrong way.
   The run ended at 5 s with STOP (ACK received).
2. 12:24:40 The firmware was re-flashed. On reboot it sent the drive **"stop and hold"
   (register 2 = 0x0701)**. The motor started running and the MATLAB Stop button (also 0x0701)
   did not stop it. The operator reported it.
3. ~12:28 An E-STOP (0x0700) was sent directly from the PC: drive mode 0x0200, speed 0. Stopped.
   The position counter showed 1 539 242 counts ≈ **296 output revolutions**.

## Cause

Encoder A/B reversed relative to the motor leads (conflict C-M3: the drive manual and the motor
sheet disagree on red/orange). Both of the drive's own loops — speed (Mode 1) and position hold
(0x0701) — then have positive feedback and drive the motor to full speed. "Stop and hold" is a
position loop, so it ran away too. Only E-STOP (0x0700, motor power off) is independent of the
encoder.

Contributing: the firmware used "hold" for STOP, for the watchdog, for fault handling **and at
boot**, and the re-flash rebooted the Uno with the battery connected. No hardware switch was
available; the battery connector is the only cut-off.

## Corrective actions

| Action | Status |
|---|---|
| Every firmware stop (Stop button, boot, watchdog, Modbus fault) uses 0x0700, motor power off; "hold" is never commanded | DONE, flashed 12:30 (emulator test reproduces the incident) |
| Runaway guard: speed opposite to the command, or > 2×cmd + 40 rpm, for 2 samples → E-STOP + `$ERR …runaway: wrong way, swap encoder pins 10/11` | DONE, flashed |
| App button renamed "Stop (power off)" | DONE |
| Swap red/orange encoder wires at drive pins 10/11 (battery out) and re-test at 20 rpm | PENDING |
| Fit a power switch or anti-spark connector; never re-flash with the battery connected | PENDING (operator) |
